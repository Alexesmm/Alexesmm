I build practical software across web development, legacy and embedded systems, and data. I enjoy turning rough ideas into reliable projects that solve real problems.

- [SITH++](https://github.com/Alexesmm/sith-programming-language) — an esoteric programming language and Python translator created while exploring programming-language concepts.

My recent private work includes full-stack systems for management, automation, reporting, and client-facing web experiences.
